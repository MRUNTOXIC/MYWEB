# Hackathon Management System

A full-stack hackathon management dashboard built with Next.js 15, Express, and MongoDB.

## Structure

```
├── hackathon-website/       # Landing page (Next.js)
├── hackathon-dashboard/     # Dashboard (Next.js 15 + TypeScript + Tailwind)
└── backend/                 # API (Express + MongoDB)
```

## Tech Stack

- **Frontend:** Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Zod
- **Backend:** Express 4, MongoDB, Mongoose, JWT, bcrypt
- **Database:** MongoDB (local)

## Setup

### Backend
```bash
cd backend
npm install
# create .env with:
# PORT=5001
# MONGO_URI=mongodb://127.0.0.1:27017/hackathonDB
# JWT_SECRET=your_secret
npm run dev
```

### Dashboard
```bash
cd hackathon-dashboard
npm install
npm run dev
# runs on http://localhost:3001
```

## Features

- JWT Authentication (Leader / Member roles)
- Team registration & invitation system
- Internet credentials with password reveal
- QR Pass generation
- Project submission
- Announcements
- Dark futuristic glassmorphism UI
